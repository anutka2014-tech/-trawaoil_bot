# Инструкция: как запустить бота на Railway.app

> Написано для тех, кто никогда не делал это раньше.
> Каждый шаг — одно простое действие.

---

## Что такое GitHub и Railway — простыми словами

**GitHub** — это облачная папка для кода. Туда ты загружаешь файлы бота,
чтобы Railway мог их забрать.

**Railway** — это компьютер в интернете, который работает 24/7.
Он возьмёт твои файлы с GitHub и запустит бота.

Схема: твои файлы → GitHub → Railway → бот работает всегда.

---

## Часть 1. Создай аккаунт на GitHub

1. Зайди на сайт: **github.com**
2. Нажми кнопку **Sign up** (верхний правый угол)
3. Введи email, придумай пароль и имя пользователя
4. Подтверди email — придёт письмо, нажми кнопку в нём
5. На все вопросы про план выбирай **Free**

✅ Аккаунт готов.

---

## Часть 2. Загрузи файлы бота на GitHub

### Создай репозиторий (это просто папка на GitHub)

1. После входа нажми зелёную кнопку **New** (слева вверху)
2. В поле **Repository name** напиши: `trawa-bot`
3. Выбери **Private** (чтобы файлы не были видны всем)
4. Нажми зелёную кнопку **Create repository**

### Загрузи файлы

1. На странице репозитория нажми **uploading an existing file**
   (ссылка в центре страницы)
2. Открой на своём компьютере папку **trawaoil_bot** в Finder
3. Выдели ВСЕ файлы внутри папки (Cmd + A)
4. Перетащи их в браузер — в зону загрузки (где написано "Drag files here")
5. Подожди пока все загрузятся
6. Внизу страницы нажми зелёную кнопку **Commit changes**

⚠️ Файл **.env** НЕ загружай — в нём токен, он должен оставаться только у тебя.
Если он попал в список — убери галочку рядом с ним.

✅ Файлы на GitHub.

---

## Часть 3. Создай аккаунт на Railway

1. Зайди на сайт: **railway.app**
2. Нажми **Login** → выбери **Login with GitHub**
3. GitHub попросит разрешение — нажми **Authorize**

✅ Аккаунт Railway создан и привязан к GitHub.

---

## Часть 4. Создай проект и подключи бота

1. На главной Railway нажми **New Project**
2. Выбери **Deploy from GitHub repo**
3. Нажми **Configure GitHub App** → выбери свой аккаунт
4. Выбери репозиторий **trawa-bot**
5. Нажми **Deploy Now**

Railway начнёт загружать файлы. Появится окно с логами (текст бежит) — подожди.

---

## Часть 5. Добавь токен бота (обязательно!)

Без этого шага бот не запустится.

1. В Railway кликни на свой проект
2. Слева найди вкладку **Variables**
3. Нажми **New Variable**
4. В поле **Name** напиши: `BOT_TOKEN`
5. В поле **Value** вставь токен бота
   (он выглядит так: `8302722597:AAEABqv0WkT99OIa0_E_NoGLarci927XX00`)
6. Нажми **Add**

> Где взять токен? Открой файл `.env` в папке trawaoil_bot на своём компьютере —
> там написано `BOT_TOKEN=...` — вот это значение и скопируй.

После добавления переменной Railway автоматически перезапустит бота.

---

## Часть 6. Проверь что бот работает

1. В Railway перейди во вкладку **Deployments**
2. Найди последний деплой — должно быть написано **Active** (зелёный)
3. Нажми на него → справа появятся логи
4. Ищи строку: `TRAWA Bot запущен 🌿`

Если видишь эту строку — бот работает! 🎉

---

## Как обновлять бота в будущем

Когда ты изменила файлы на компьютере и хочешь обновить бота:

1. Зайди на **github.com** → в репозиторий `trawa-bot`
2. Найди нужный файл (например `content.py`) и нажми на него
3. Нажми иконку карандаша (✏️) справа вверху
4. Внеси изменения прямо в браузере
5. Нажми **Commit changes**

Railway увидит изменение и автоматически перезапустит бота через 1–2 минуты.

---

## Если что-то пошло не так

**Бот не отвечает:**
→ Проверь вкладку Deployments в Railway — нет ли ошибки (красный цвет)
→ Убедись что BOT_TOKEN добавлен правильно (без пробелов)

**В логах написано "BOT_TOKEN не найден":**
→ Зайди в Variables → проверь что переменная называется `BOT_TOKEN` (большими буквами)

**Бот отвечает, но старая версия:**
→ В Railway нажми **Redeploy** на последнем деплое
