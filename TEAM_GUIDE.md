# TRAWA Bot — Инструкция для команды

---

## 📁 Структура проекта

```
trawaoil_bot/
├── bot.py                  — запуск бота
├── handlers.py             — логика кнопок и команд
├── keyboards.py            — кнопки меню
├── content.py              — ВСЕ тексты и фото товаров
├── content_dynamic.json    — акции (редактируются без перезапуска)
├── analytics.py            — аналитика
├── contacts.csv            — контакты пользователей (создаётся автоматически)
├── analytics_log.txt       — лог событий
├── .env                    — токен бота и настройки (не передавать никому!)
├── CONTENT_FOR_REVIEW.md   — тексты для редактуры командой
└── TEAM_GUIDE.md           — эта инструкция
```

---

## ✏️ Как менять тексты товаров

1. Открой файл **`CONTENT_FOR_REVIEW.md`** — там все тексты в удобном виде
2. Внеси правки прямо в этом файле
3. Передай разработчику — он перенесёт изменения в `content.py`
4. Разработчик перезапускает бота

> ⚠️ Напрямую редактировать `content.py` — только если понимаешь структуру Python.
> Одна лишняя запятая может сломать бот.

---

## 🖼️ Как менять фотографии товаров

В файле `content.py` в самом начале — список ссылок на фото:

```python
IMG_LINSEED = "https://imgproxy.trawaoil.ru/..."
IMG_HEMP    = "https://imgproxy.trawaoil.ru/..."
```

Чтобы поменять фото:
1. Найди нужную ссылку на фото (прямая ссылка на изображение)
2. Передай разработчику с указанием какой товар
3. Разработчик меняет ссылку в `content.py` и перезапускает бота

## 🔥 Как менять акции (БЕЗ перезапуска бота)

Открой файл **`content_dynamic.json`** — там список акций.

Пример:
```json
{
  "акции": [
    {
      "name": "Сеты по специальной цене",
      "description": "Выгодные наборы масел TRAWA — экономия до 20%.",
      "url": "https://trawaoil.ru/c/sety-...",
      "photo_url": ""
    }
  ]
}
```

**Чтобы добавить акцию** — скопируй блок `{ }` и добавь новый через запятую.
**Чтобы убрать акцию** — удали её блок `{ }`.

> ✅ Акции обновляются мгновенно — перезапуск бота не нужен!

## 👥 Как получить список контактов пользователей

Когда пользователь нажимает /start в боте, его данные автоматически сохраняются в файл **`contacts.csv`**.

**Что сохраняется:**
- Дата и время первого/повторного входа
- Telegram ID
- Username (@никнейм)
- Имя и фамилия

**Чтобы получить файл:**

1. Узнай свой Telegram ID (напиши боту @userinfobot)
2. Открой файл `.env` и замени `ВАШ_TELEGRAM_ID` на своё число:
   ```
   ADMIN_ID=123456789
   ```
3. Перезапусти бота
4. Напиши боту команду: `/contacts`
5. Бот пришлёт тебе CSV-файл — открой в Excel или Google Таблицах

> 📞 Номер телефона бот не собирает автоматически — Telegram это запрещает
> без явного согласия пользователя. Для сбора телефонов нужна отдельная доработка.

## 🌐 Как запустить бота на сервере (постоянная работа)

Самый простой способ — **Railway.app** (бесплатный тариф, не нужны технические знания).

**Шаги:**
1. Создай аккаунт на [railway.app](https://railway.app)
2. Загрузи папку `trawaoil_bot` на GitHub (попроси разработчика)
3. В Railway: New Project → Deploy from GitHub → выбери репозиторий
4. В настройках добавь переменные окружения (Environment Variables):
   - `BOT_TOKEN` = токен бота
   - `ADMIN_ID` = твой Telegram ID
5. Бот запустится автоматически и будет работать 24/7

**Альтернатива:** Render.com — аналогичный сервис, тоже бесплатный.
